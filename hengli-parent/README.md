# hengli-parent

衡理公共父 POM，随 [衡理](https://github.com/henglian-ai/hengli) 开源。

各 Java 模块的 Maven 父工程。统一 Java 17，并锁定 Spring Boot、Spring Cloud、Spring AI、MyBatis-Plus 等依赖版本。服务和组件都从这里继承，不单独启动。
